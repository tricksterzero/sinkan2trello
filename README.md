# "新刊.net to Trello"とは？
[新刊.net][Sinkan]で作成できる新刊の発売情報のiCalデータを読み込んで、[Trello][Trello]のカードとして登録するスクリプトです。

## 前提
[新刊.net][Sinkan]と[Trello][Trello]のアカウントが必要です。また[新刊.net][Sinkan]のキーワード登録が完了している必要があります。ただし後からキーワードを追加しても問題ないです。

## 使い方
### 初期設定
#### "新刊.net to Trello"の展開
適当なフォルダを作成してzipファイルの中身を展開してください。展開したファイルの`config.init.js`を`config.js`にリネームしてください。必要な情報を取得して入力するので`config.js`をテキストエディタで開いておいてください。

#### Node.jsのインストール
[Node.js](https://nodejs.org/ja)からNode.js環境のインストーラをダウンロードします。"推奨版"がオススメです。ダウンロードしたファイルを実行してインストールしてください。

#### 必要なライブラリのインストール
コマンドプロンプトを起動して"新刊.net to Trello"を展開したフォルダに移動してください。それから以下のコマンドを実行してください。必要なライブラリが1つインストールされます。

```sh
npm install
```

#### 新刊.netのiCalデータのURLの取得
ブラウザから[新刊.net][Sinkan]にログインします。画面下の方にある[ICAL形式](https://sinkan.net/?action_ical_info=true)を開くと"カレンダーのアドレス"が表示されます。URLをコピーして`config.js`の所定の位置にペーストします。

#### Trello APIキーとトークンの取得
ブラウザから[Trello][Trello]にログインします。その状態で[Power-Up & 統合](https://trello.com/power-ups/admin)を開きます。

"新規"ボタンを押してAPIキー取得に必要なPower-Upを作成します。項目の入力例を以下に示します。

- "Power-Upまたは統合を新規作成"には後から分かる名前を付けてください。"APIKey発行用"などが適切でしょう。
- "ワークスペース"は自分のワークスペースを選択してください。
- "IframeコネクタURL (Power-Upで必要)"は初期値のままで大丈夫です。
- "メールアドレス"と"サポートへお問い合わせ"には自分のメールアドレスを入力してください。
- "作者"には自分の名前を入力してください。本名でなくても問題ないと思います。

"作成"ボタンを押して完了です。

ここで作成したPower-Up、例のままであれば"APIKey発行用"を開きます。更に左のメニューにある"APIキー"を開きます。まず"APIキー"が表示されているのでコピーして`config.js`の所定の位置にペーストします。

続いて、APIキーの右側にある文章の中の"トークン"のリンクをクリックします。"アカウントへのアクセスを許可"するためのページが開くので"許可"ボタンを押します。トークンが表示されるのでコピーして`config.js`の所定の位置にペーストします。

#### Trelloに新刊情報の出力先を作成
[Trello][Trello]を開いて"新しいボードを作成"します。任意の名前を設定してください。ここでは例として"新刊情報"という名前で作成したことにします。

作成したボードにリストを3つ作成します。任意の名前を設定してください。ここでは例として"購入前","購入済","不要"という名前で作成したことにします。

#### Trelloの出力先のボードIDとリストIDを取得
コマンドプロンプトを起動して"新刊.net to Trello"を展開したフォルダに移動します。そして以下のコマンドを実行してください。

```sh
node info.js
```

ボードの一覧とエラーメッセージが表示されます。ボードの一覧から先ほど作成したボード名を探します。対応するIDをコピーして`config.js`の所定の位置にペーストします。

`config.js`を保存してからもう一度、以下のコマンドを実行してください。

```sh
node info.js
```

今度はボードの一覧に続いてリストの一覧が表示されます。まず新刊情報を登録するリストを決めます。例として"購入前"に対応するIDをコピーして`config.js`の所定の位置の一番左にペーストします。その後、残りの2つのリスト、"購入済"と"不要"に対応するIDをそれぞれコピーして所定の位置にペーストします。

以上で設定は完了です。

---

### 実行方法
コマンドプロンプトを起動して"新刊.net to Trello"を展開したフォルダに移動します。そして以下のコマンドを実行してください。

```sh
node index.js
```
